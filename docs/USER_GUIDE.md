# CCMS 用户操作指南

> 最后更新：2026-05-22

## 1. 系统概述

校园社团管理系统（CCMS）是一个面向大学校园的社团管理平台，支持社团创建、活动审批、财务管理、任务委派等功能。

**访问地址**: `http://localhost:3000`

## 2. 公开浏览（无需登录）

### 首页
访问 `/` 即可看到所有活跃社团的展示首页，包括社团卡片（封面图、名称、简介、成员数、活动数）。点击任意社团卡片进入详情页。

### 社团详情页
访问 `/club/:id` 可查看社团的详细信息：封面大图、社团名称、创始人、详细简介、成员数量统计、近期活动列表。

## 3. 注册与登录

### 注册
1. 点击首页右上角「加入我们」或导航至 `/register`
2. 填写用户名、邮箱、密码、学号（必须 11 位数字）
3. 提交后自动登录并跳转管理后台

### 登录
1. 点击首页右上角「登录」或导航至 `/login`
2. 输入邮箱和密码
3. 登录成功后跳转管理后台（`/admin`）

### 强制重设密码
系统管理员首次登录时会被要求重设密码。新密码需包含大写字母、小写字母和特殊符号。

## 4. 管理后台功能（需登录）

登录后进入 `/admin` 控制台。左侧边栏提供导航：

| 模块 | 路径 | 说明 |
|------|------|------|
| 社团管理 | `/admin/clubs` | 创建、查看、编辑、删除社团 |
| 成员管理 | `/admin/clubs/:id/members` | 添加/移除成员、调整角色 |
| 活动管理 | `/admin/activities` | 创建活动、提交审批 |
| 审批中心 | `/admin/approvals` | 审批或驳回活动申请 |
| 社团任务 | `/admin/club-tasks` | 发布任务给社团成员（支持多负责人） |
| 我的待办 | `/admin/todos` | 个人任务 + 被分配的社团任务 |
| 财务管理 | `/admin/finance` | 收支录入、分类统计、月度报告 |

## 5. 常见错误与处理

| 错误提示 | 原因 | 处理方法 |
|---------|------|---------|
| "租户上下文缺失" | 未设置租户编码 | 在顶栏输入 `default` |
| "登录状态已失效" | Token 过期 | 重新登录 |
| "暂无权限执行该操作" | 角色权限不足 | 联系管理员 |
| "社团未找到" | 社团 ID 不存在 | 检查社团列表 |
| "社团任务权限不足" | 不是社团 founder/admin | 联系社团管理员 |

## 6. 角色说明

| 角色 | 权限范围 |
|------|---------|
| **系统管理员** (system_admin) | 全部权限：管理所有社团、成员、活动、财务 |
| **社团管理员** (club_admin) | 管理自己所在社团（需是 founder/admin） |
| **租户管理员** (tenant_admin) | 管理当前租户下所有资源 |
| **学生** (student/member) | 浏览社团、加入/退出、创建活动、管理个人待办 |
